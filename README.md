# abdessamadaitbrahim.github.io

Personal portfolio of Abdessamad Ait Brahim. Plain HTML, CSS and JavaScript, no framework.

- Edit project data in `tools/make_content.py`, then run `python tools/make_content.py && python tools/build.py`.
- Put the CV at `assets/cv/Abdessamad_Ait_Brahim_CV.pdf`; the download button appears automatically.
