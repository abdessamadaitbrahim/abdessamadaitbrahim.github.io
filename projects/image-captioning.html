Image Captioning on Flickr30k

Four image-to-text architectures compared with BLEU on Flickr30k, plus a Flask app that captions an uploaded image.

02The problem

The problem

Generate a natural-language description of an image. The project compares encoder-decoder families on the Flickr30k dataset, from CNN with recurrent decoders to a Transformer decoder and the pretrained BLIP vision-language model.

03What I built

What I built

  • VGG19 + LSTM, InceptionV3 + BiLSTM and InceptionV3 + Transformer (6 layers, 8 heads, d = 512) trained as encoder-decoder models; BLIP used as a pretrained reference.
  • Evaluation with BLEU-1 and BLEU-4.
  • A Flask web application with drag-and-drop image upload (JPG and PNG up to 16 MB), model selection and caption generation. BLIP is loaded only when selected, so the app runs without PyTorch otherwise.

04Results

Results

  • BLEU-1 / BLEU-4: VGG19 + LSTM 0.5832 / 0.1720, InceptionV3 + BiLSTM 0.6037 / 0.1968, InceptionV3 + Transformer 0.6132 / 0.2114.
  • The Transformer decoder gives the best scores among the trained models.
