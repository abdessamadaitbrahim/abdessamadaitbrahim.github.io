02The problem

The problem

Detect suspicious SSH activity as it happens instead of reading authentication logs by hand.

03What I built

What I built

  • Real-time monitoring of SSH authentication events from the system log.
  • Anomaly detection on connection patterns with an Isolation Forest.
  • Automatic blocking of suspicious IP addresses with iptables and email notifications through Gmail SMTP.
  • A Flask web dashboard to inspect logs and run tests, with automated unit tests scheduled by cron.

04Results

Results

  • Events are stored locally in a log file; Elasticsearch is listed in the repository as a possible future improvement, not as a current feature.
