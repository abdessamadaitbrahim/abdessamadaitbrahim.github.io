Facial Emotion Recognition: VGG vs ResNet

VGG and ResNet built from scratch in PyTorch on 49,779 face images. ResNet reaches 75.4% test accuracy with 34 times fewer parameters.

02The problem

The problem

Classify a face image into one of seven emotions (angry, disgust, fear, happy, neutral, sad, surprise). The aim is a fair architectural comparison: both networks are trained from scratch, with no pretrained weights, using exactly the same split, augmentation, optimizer, scheduler and number of epochs.

03What I built

What I built

  • Implemented a VGG-style network (five blocks, about 44.9 M parameters) and a compact residual network (about 1.30 M parameters) in PyTorch.
  • Trained both on 49,779 grayscale images resized to 98 x 98, with a stratified 80/20 split (39,823 train, 9,956 test).
  • Used Adam (learning rate 1e-3, weight decay 1e-4), an exponential scheduler, random flips and rotations up to 10 degrees, for 50 epochs.
  • Analysed training curves, class imbalance and overfitting.

04Results

Results

  • ResNet: 75.4% test accuracy, 0.737 test loss. VGG: 66.7% test accuracy, 0.889 test loss.
  • ResNet has about 34 times fewer parameters than VGG: skip connections ease gradient flow and global average pooling replaces the large fully-connected layers.
  • ResNet overfits more (11.9-point train-test gap) but still generalises better; its test loss stops improving after about 25 epochs, so early stopping would help.
